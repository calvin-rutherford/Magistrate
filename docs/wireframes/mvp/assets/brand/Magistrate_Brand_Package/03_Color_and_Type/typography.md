# Magistrate Typography

## Wordmark and editorial display

- Primary family: **Bodoni Moda**
- Weight: 500 Medium
- Usage: Magistrate wordmark, major editorial headings, launch material
- Do not use it for controls, status text, chat copy, or dense information.
- Source: https://fonts.google.com/specimen/Bodoni+Moda

## Interface

- Primary family: **Inter**
- Weights: 400 Regular, 500 Medium, 600 Semibold, 700 Bold
- Usage: chat, controls, drawer, status, cards, activity traces, documentation
- Source: https://fonts.google.com/specimen/Inter

## Hierarchy

- Wordmark: Bodoni Moda Medium
- Display heading: Bodoni Moda Medium
- Screen title: Inter Semibold
- Body and chat: Inter Regular
- Button and important label: Inter Semibold
- Metadata: Inter Regular

Magistrate has no permanent tagline. Descriptive campaign copy must never be attached to the logo as a fixed lockup.
