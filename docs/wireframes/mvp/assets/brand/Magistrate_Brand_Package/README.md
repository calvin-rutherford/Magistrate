# Magistrate Brand Package

Magistrate is a voice-first mobile command surface for Firstmate and its connected AI fleet. The identity is quiet and predominantly neutral during ordinary use, then awakens in proportion to system activity.

## Core rule

**CALM AT REST. SPECTRAL WHEN ALIVE.**

- Dormant and ordinary UI: monochrome, restrained, trustworthy.
- Listening and normal active AI states: restrained cyan and blue-violet.
- Executing: more visible but still controlled functional spectrum.
- Immersive voice and major activation: full green -> cyan -> violet -> magenta organic identity.
- Keep ordinary use approximately 90-95% visually neutral.

## Canonical identity

- The public name is always **Magistrate**. There is no permanent tagline.
- The primary mark remains one inverted triangle containing one centered spiral.
- Bodoni Moda is the wordmark face; Inter is the interface face.
- Dark and light are equal, complete environments.
- Atmospheric backgrounds remain minimal, glass-compatible, and subordinate to content.
- App icons, logo construction, neutral foundations, and the organic active artwork remain unchanged.

## Canonical product model

- The conversation is the center of gravity: familiar modern AI chat with fleet control underneath.
- Conversational voice is the default and remains inside the active Firstmate or agent conversation.
- Immersive Voice Call mode preserves the full organic spectral environment as an optional experience.
- The drawer order is Attention, Fleet Summary, Recent Activity, Connections, Settings.
- Firstmate remains primary. Spawned agents reuse the same real conversation design.
- Attention uses compact action cards; normal answers remain prose-first.
- Connections represent real authenticated services and health, never fake toggles.
- The mobile UI must remain stable through keyboard, safe-area, orientation, and drawer changes.

- `00_Brand_Guide`: Updated canonical PDF guide.

- `04_UI_States`: Updated conversation, operational, voice, light/dark, and background boards.
- `05_Marketing`: Unchanged organic active-state launch artwork.
- `06_Implementation`: Updated JSON/CSS tokens, motion rules, behavior contract, and change log.

Start with the PDF guide, then use `06_Implementation/component-behavior.md` and the token files for implementation.
