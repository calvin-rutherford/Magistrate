## Short project description

**Magistrate — engineering-assistant integration candidate.** Composed a
provider-native Chat/Voice interface with authenticated repository objectives,
durable resource accounting and request-bound decision support. Designed the
personal execution path to refuse unsupported runtime limits rather than treat
configuration or model prompts as enforcement.

## Résumé-style bullets

- Integrated FastAPI and Expo surfaces around one owner-scoped canonical
  conversation, preserving authorization, idempotency and structured execution
  evidence across disconnect/recovery boundaries.
- Implemented transactional personal resource reservations, frozen objective
  provenance, measured terminal settlement and stale-decision refusal, with
  disposable integration tests covering concurrency and adversarial inputs.
- Produced content-free read-only diagnostics, an operator runbook, and explicit
  automated/deployment/device acceptance boundaries; documented unresolved
  runtime and dependency gates instead of presenting a false release verdict.

## Interview explanation

“The central challenge was distinguishing intent from authority and observation.
A model proposing work, a queue acknowledging it and a worker completing it are
three different facts. I kept personal mode independent of commercial billing,
not independent of authentication or resource controls. When the pinned runtime
did not expose enforceable limits, I retained a closed publication gate and made
that limitation visible in the API, tests and demo. That is a reviewable engineering
outcome, but not yet a working personal execution release.”

## Avoid these claims

Do not say “production-ready,” “fully autonomous,” “two-worker sandbox proven,”
“APNs delivered on iPhone,” “streaming native voice validated,” “security audit
clean,” or “deployed end-to-end” for this candidate. Distinguish inherited
foundation/UI/native contributions from this lane's composition and acceptance
work. See exact integration inputs and remaining gates in the acceptance report.
