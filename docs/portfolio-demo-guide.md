## Future live owner loop — BLOCKED / NOT RUN

Requires separate operator authorization, the canonical UI adapter validated, and
all runtime/dependency gates resolved. The [runbook](portfolio-runbook.md) specifies
GitHub App authorization and the disposable one-file demo repository. Never remove
the fail-closed check to make a demo appear successful.

| Scenario | Required evidence |
|---|---|
| Login and kill/reopen | Exact principal restored; canonical rows retained; expiry/revoke/logout clear authority. |
| Ordinary question/quoted instruction | Conversational reply, zero objective/worker publication. |
| Explicit bounded objective in disposable authorized repo | Immutable objective/context IDs, reservation, queue receipt, structured acceptance and actual worker event. |
| Disconnect/restart during work | Same objective/run, no duplicate dispatch or refunded unknown work; truthful recovering state. |
| One/two-worker and spend limits | Runtime rejects a third slot and stops at actual per-objective ceiling; measured terminal usage. Ledger-only tests are insufficient. |
| Need input, approve and deny | Producer-bound run/request/scope/expiry; exact current decision and revision; one canonical confirmed answer. |
| Complete or cancel | Structured terminal event and reviewed repo artifact; cancellation request alone is not completion. |
| Memory save/retrieve/delete | Explicit owner/project-scoped memory; future retrieval removed while already frozen handoff is unchanged. |

## Physical iPhone matrix — every row NOT RUN here

Record exact Gateway/candidate revision, EAS build ID/build number, device/iOS,
network and timestamp; attach only redacted evidence.

- Native login, app kill/reopen, expiry, online logout and server revoke.
- Cold/warm notification tap through session restoration; stale/expired/replayed
  decision opens read-only, no approval sent by tapping.
- Real permission allow/deny, Expo token registration, APNs/provider receipt,
  visible phone notification, and owner viewing—record these separately.
- Foreground microphone/STT/TTS and shared Chat/Voice conversation; background,
  lock, interruption and permission-denied recovery.
- Action Button/Shortcuts foreground navigation on the installed build; no
  claim of background capture or native streaming from JavaScript/browser tests.
- Wi-Fi/cellular handoff and offline resume with canonical-message recovery.

An old EAS build, Expo Go, simulator, web browser, fixture or code inspection is
not current-candidate physical acceptance. If any row cannot run, retain NOT RUN;
do not replace it with a screenshot of a mock.
