Shared prompt: `stylized-concept` full-screen mobile ambient background; refined minimal digital matte painting; portrait-first with quiet center/upper negative space; low contrast and soft gradients; no text, logos, watermarks, people, buildings, animals, UI, or sharp detail. Variants use dawn indigo/apricot, day slate/teal, dusk plum/terracotta, and night navy/violet palettes.
